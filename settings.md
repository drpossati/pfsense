## <center> Configuração PFsense 2.8 - Hardware FW-7535D </center>

### <center> Mapeamento de Portas </center>

| Portas | Função | Descrição |
|:--:| :------------------: | :----------------: |
| 01 | WAN1 - Link de Fibra | Link de Internet principal (OI) |
| 02 | WAN2 - Link Satélite | Link de Internet secundário (StarLink) |
| 03 | LAN - Rede Cabeada   | Conexão com a Rede UTP |
| 04 | WLAN - Rede Sem Fio  | Conexão com a Rede aberta |
| 05 | SYNC - pfSync / XMLRPC | Conexão entre as boxes para sincronização |
| 06 | MGMT / VLANs           | Porta reservada para gerenciamento ou trunk de VLANs adicionais |
